# Circular

**[AGENTS.md](AGENTS.md) is how you author a pipeline here. Read it.** This file is a
short pointer to those authoring instructions.

It covers the execution model you have to hold before writing code (active actors running
as tasks, no end, branching by fan-out and filter, transforms belonging to the destination inlet,
ordinary cycles, the journal as the authority), what you are connected to, binding an agent
harness, authoring with two worked examples, deploying, observing, pausing and replaying,
the limits you work under, and the models that most often mislead someone arriving from a
workflow engine.

If a human is setting the machine up rather than authoring, [README.md](README.md) and
[QUICKSTART.md](QUICKSTART.md) are theirs.
